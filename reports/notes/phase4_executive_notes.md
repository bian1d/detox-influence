论文 Chapter 6 的五个发现全是**排名层面**的（例：种族模板和性向模板的 top rollout 几乎不重叠）。

## 核心实验 E3：怎么测"搞没搞坏"

### 修正长什么样（关键直觉）

假设失败会给公式塞进一个"污染项" Δ̃。它污染的正是**"Fisher 的逆"那一项**。

- 原来：记 p = F⁻¹ g_f（评估方向经过 Fisher 逆变换），影响值 = −pᵀ s_m
- 现在：那个逆从 F⁻¹ 变成 (F − Δ̃)⁻¹

用一个矩阵版的高中近似 1/(a−b) ≈ 1/a + b/a²：

    (F − Δ̃)⁻¹ ≈ F⁻¹ + F⁻¹ Δ̃ F⁻¹

代进去，修正后影响值 = 原来的 + 一个小尾巴：

    I_corr(z_m) = −pᵀ s_m  −  qᵀ s_m
                  ╰─原来的─╯   ╰─新尾巴─╯       其中 q := F⁻¹ Δ̃ p

**省钱点**：q 只跟评估方向有关、跟具体哪条 rollout 无关。所以 q 算一次，
套到全部两万条 rollout 上（每条一次点积）。加修正和原来一样便宜。

### 测完比三样东西

1. **排名相关性（Spearman）**：看整条名单顺序对不对。越接近 1 越好。
2. **top-50 重叠度（Jaccard）**：专门看头部。加修正前的 top-50 和加修正后的 top-50
   重合几条？因为 Chapter 6 真正关心头部那几十条，整体相关性高也可能头部被洗牌，
   这是补 Spearman 盲区的放大镜。
3. **污染占比标尺 ‖Δ̃p‖ / ‖g_f‖**：一个"温度计"，不用等排名就先扫一眼污染大不大。
   - 分母 ‖g_f‖：评估方向本身的长度（基准）
   - 分子 ‖Δ̃p‖：污染项作用在实际用到方向上的偏移长度
   - 比值 = 污染偏移相对原信号的比例。0.05 = 污染只占 5%，可忽略；0.4 = 占 40%，搅了。

### 判定
- **转机**：4 个目标全部 Spearman > 0.95，且温度计 < 0.1。
- **锤死**：任一目标 Spearman < 0.9，或温度计 > 0.3。
- 中间地带：才动用昂贵的全套精确计算去拍板（见下）。

## 三个"不补会算错"的坑（agent 必须注意）

### 坑 1：在两百多万维空间里量向量长度会被噪声淹没（影响 E2、E3）

想知道真向量 G 多长，但手上只有带噪声的估计 Ĝ = G + 噪声。
天真地算 ‖Ĝ‖²，会多出一项 ‖噪声‖²，这一项**永远为正、加不没**，
在两百多万维下巨大，把真正的 ‖G‖² 淹没。
→ 不补这个，E2 会量出虚高的 ‖G‖，误判 θ* 严重偏离、直接误判锤死。

**解法 split-half（跟 K-FAC 无关，是交叉验证那个家族的思路）**：
把样本随机劈两半 A、B，各自估 Ĝ_A、Ĝ_B（两半噪声独立）。
不算各自长度，而算两者**内积** ⟨Ĝ_A, Ĝ_B⟩。
因为两半噪声独立，噪声乘积平均下来 ≈ 0（正负抵消），不像 ‖噪声‖² 永远为正。
所以内积干净地估出 ‖G‖²，没有虚高偏差。多劈几次取平均更稳。
一句话：自己跟自己点积会把噪声平方累加（有偏）；两个独立估计互相点积，噪声因独立而抵消（无偏）。

### 坑 2：E1 原计划想测一个测不了的东西

有效奖励 R̃ = r(x,y) − β·Σ[log π_θ* − log π_ref]。
一旦把 prompt x、回答 y、模型 θ* **全固定**，R̃ 就是个**确定的数**：
RoBERTa 对固定文本打同一个分，固定模型对固定 y 算出同样的 log prob。重算一百遍都一样。
→ 所以"固定回答重采样看 R̃ 抖多少"自相矛盾——回答固定了 R̃ 就钉死了，没得抖。删掉。
ICC=0.892 那个差异来自**换不同的回答 y**，不是同一回答的重复噪声。
E1 改成测真正有意义的：同一 prompt 下换不同回答的 R̃ 差异，
有多少来自奖励 r 本身的形状、多少来自 KL 偏离。
（公式：Var[R̃] = Var[r] + β²·Var[KL] − 2β·Cov[r, KL]，逐 prompt 算三项占比。）

### 坑 3：全套精确计算的数值精度误差 + 解法器选择

什么叫数值精度误差：计算机存小数只有固定位数（fp32 约 7 位、fp64 约 16 位），
每次运算最后一两位有舍入误差。单次微不足道，但**迭代成千上万次、每次在前一次结果上接着算**，
误差会累积甚至放大，最后结果可能面目全非。

为什么全套精确计算（解 (F−Δ̃)p_corr = g_f）尤其要担心：
- 它是**迭代解法器**，可能跑几百上千步，有累积问题（一阶修正"算一次不迭代"则没有）。
- 矩阵 (F−Δ̃) 性质不好（"不定"：有的方向拉伸、有的翻转），迭代容易不收敛或收敛慢，误差更易累积。

两个防护：
1. **能不用就不用**：只在一阶修正落在"说不清的模糊地带"（Spearman 0.9~0.98）才动用全套。
2. **挑对解法器**：用 **MINRES**（对不定矩阵友好），不用 CG（要求矩阵正定，这里不满足会崩），
   也不用 GMRES（那是给非对称矩阵的，杀鸡用牛刀）。要求 agent 记录迭代残差、跑完检查收敛，
   不许闷头信结果。底层累加已用 fp64，比 fp32 稳得多。

## 和 PBRF 那条线的关系（Yide 的决策）

PBRF 那条线是用**理论推导辩护**"假设不成立也没关系"。
Phase 4 的 E3 是**直接拿实验测**"到底有没有关系"。
建议：**先跑 E3，用数字说话**。
- E3 测出污染小（转机）→ 不需要 PBRF 辩护，直接说"实测过、误差这么大、排名没变"，更硬气。
- E3 测出污染大（锤死）→ 再回头用 PBRF 做解释。
所以 PBRF 那条线先挂着别急着推全套，等 E3 数字出来再决定要不要它。

## 给 agent 的最低纪律（照 CLAUDE.md 的精神）

- 失败不许偷偷降标准：surface 出"测了什么 vs 阈值、试过什么、三个假设、什么证据能区分"。
- 所有高维范数平方/二次型一律 split-half，不许单批自积。
- E2/E3 的采样确实是 on-policy（y ~ π_θ*），不是复用训练 rollout。
- E3 里 Fisher 的 pseudo-label 和算 A 用的回答必须是同一次抽样的同一个 y。
- 一阶 Spearman 采不采信，明确依据温度计 ‖Δ̃p‖/‖g_f‖ 的实测值。
- "距离最优""误差小"等是对数字的解读，必须和实测数字分开写。

## k3 与缓存的处置（新坑版理由）

**k3（E5）：只做诊断版重算，不重训 PPO。**
- KL 估计器只进 R̃，不进 Fisher F（F 是纯 score 外积，与 k1/k3 无关）。所以 E5 拿现有 θ* 和
  现有 rollout 把标量 R̃ 用 k3 重算即可，几分钟，不碰训练、不碰 Fisher。
- 不重训的理由不再是"别动已交付的成品"，而是：社区不开 k3、也不扩 paper，没必要花几小时重训
  整条管线。E5 的目的是搞清"ICC=0.892 里有多少是 k1 估计器自己造的假象"——若一大半是 k1 人为
  引入的，那是**偏转机**的信号（真实策略次优没那么严重），记一笔。

**缓存的 F⁻¹g_eval（184G，data/ekfac/）：Phase 4 期间别删，但理由变了。**
- 它和 k1/k3 无关——F⁻¹ 只依赖 score function 和评估目标梯度，换 KL 估计器不改变这份缓存。
  所以"换 k3 → 缓存过时"这个推理不成立。
- 别删的理由不再是"答辩复现命根子"（论文已提交），而是：Phase 4 的 E3 直接复用缓存的
  p = F⁻¹g_f 算一阶修正、E4 复用 g_f 和 s_m，删了第一步就得重算几小时。
- **哪天 Phase 4 锤死、确定封坑换项目时，清掉它毫无心理负担。** 磁盘紧张就挪冷存储，别删。
